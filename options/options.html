Google Calendar

Not connected

Syncing uses your own Google OAuth client, so no third-party server ever sees your data. Create an OAuth client once and paste its ID below.

Use primary for your main calendar, or the long ID of a specific calendar.
How to create the OAuth client (step by step)
  1. Open Google Cloud Console → Credentials.
  2. Enable the Google Calendar API.
  3. Configure the OAuth consent screen (External, then add yourself as a test user).
  4. Create credentials → OAuth client ID → application type Web application.
  5. Under Authorised redirect URIs, add the redirect URI shown above.
  6. Copy the generated client ID into the field above and click Connect.

The redirect URI is unique to your browser profile. Re-copy it if you reinstall the extension.

Data & privacy

Extraction happens entirely in your browser. Events are stored in this browser profile's local extension storage. Nothing is sent anywhere unless you explicitly press Sync to Google Calendar, which talks directly to Google's API using your own credentials. There is no analytics and no third-party server.
